# CUMCM 论文格式自查清单

依据《全国大学生数学建模竞赛论文格式规范（2026 年修订稿）》官方版本。交稿前逐条核对；不符合本规范可能被取消评奖资格。

## 一、纸质版（8 条硬性条款）

1. **纸张/页边距**：白色 A4，上下左右页边距 ≥2.5 cm，左侧装订。
2. **承诺书/编号页**：第 1 页承诺书、第 2 页编号专用页，内容见官方专用页，不得改动。
3. **摘要页**：第 3 页为摘要专用页，含标题 + 关键词（无需翻译成英文），原则上不超一页；页码从此页开始，位于页脚中部，阿拉伯数字从 "1" 连续编号。
4. **正文**：从第 4 页起，不要目录，不超过 30 页；正文之后是附录（页数不限，须打印装订）。
5. **附录源码**：须含支撑材料文件列表 + 建模所用全部完整、可运行的源程序代码（含 EXCEL/SPSS 等交互命令）。缺源码 / 不能运行 / 运行结果与论文不符 → 可能取消评奖资格。没用程序须注明 "本论文没有用到程序"。
6. **匿名**：摘要专用页、正文、附录任何位置都不得出现参赛者身份、学校、赛区信息。
7. **参考文献**：引用他人或公开资料（含网上资料）须按科技论文规范列参考文献，并在正文引用处标注。
8. **字体字号**：字号、字体、行距、颜色不做统一要求（各赛区可另行要求）。网传 "宋体小四 / 黑体三号 / 行距 20 磅" 仅为推荐，非官方强制。

## 二、电子版（第九~十一条）

9. 参赛论文电子版与纸质版**内容及格式（含附录）完全一致**；单独文件，PDF 或 Word 之一（建议 PDF），≤20 MB，不压缩。
10. 电子版第一页必须为摘要专用页；承诺书、编号专用页**不放**电子版论文。
11. 支撑材料用 WinRAR 压成 RAR/ZIP（≤20 MB），含所有可运行源程序、自主查用的数据资料等；其文件列表放入论文附录；无支撑材料须注明 "本论文没有支撑材料"；所有文件不能含身份信息。

## 三、高频易错点（重点自查）

- 电子版误把封面 / 承诺书 / 编号页放进去，导致第一页不是摘要页。
- 附录缺完整源码，或源码不能运行、运行结果与论文不符（最常见的取消评奖原因）。
- 摘要页、页眉、图题、表注、代码注释里残留学校名 / 队号 / 姓名。
- 正文页数超 30 页。
- 支撑材料压缩包超 20 MB 或格式不是 RAR/ZIP。
- 参考文献只在文末列出、正文未标注引用位置。

## 四、给 Agent 的自查动作

拿到论文工程（LaTeX / Word 导出的 PDF）后，按上方编号逐条核对并输出勾选表：

1. 用 `fs.list` 找到主 `tex` / 文档入口与章节文件，用 `fs.read` 读摘要页与首页内容，确认电子版第一页是摘要专用页。
2. 用 `search.grep` 在全文（含图题、表注、代码注释）搜学校名 / 姓名 / 队号做匿名检查。
3. 用 `fs.list` 核对附录源码与支撑材料文件列表是否一致；必要时用 `shell.exec` 试运行关键脚本确认可运行。
4. 参考文献逐条确认正文引用处有标注。
5. 机器不可判定的项（页边距、装订、纸质版一致性）明确标注「需人工确认」，不得替用户勾选。
